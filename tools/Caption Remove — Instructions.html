Caption Remove

Strips burned-in captions (words baked into the picture) from video clips. Runs on your Mac — nothing is uploaded. Originals are never changed.

▣The folders

Desktop └── Caption Remove ├── In ← drop original clips here ├── Out ← cleaned clips appear here └── settings.txt ← caption zone + mode (filled in for you)
Every cleaned clip is a new file in Out, named like the original plus _clean.
FOX_Picky Eaters_V1.mp4 → FOX_Picky Eaters_V1_clean.mp4

⏱What to expect

Speed
About 1 frame per second. A 30-second clip ≈ 12–15 min; 2 minutes ≈ an hour. Leave batches overnight.
Quality
Nearly invisible over a plain wall, shirt or black backdrop. A hand or busy detail passing through the box can leave a soft patch for a few frames.
Output
Same resolution and frame rate as the original; the original audio is copied through untouched.
While it runs
Keep using the Mac, but don't close the lid — it pauses.

▶Step by step

  1. Get the original clip — e.g. the Download button on Frame.io. A real download, not a screen recording (much cleaner result).
  2. Drop it in Desktop › Caption Remove › In. Several clips at once is fine.
  3. Click the Caption Remove icon in the Dock. A picture window opens showing the newest clip in In.
  4. Find a frame with a caption — drag the slider at the top of the window.
  5. Drag a box around the caption. It draws in yellow. If captions move between shots, make the box tall enough to cover the highest and lowest spot you see while scrubbing. Keep it clear of faces.
    C clears the box to redraw  ·  Esc skips drawing and reuses the last saved box
  6. Press Enter. The picture window closes and a Terminal window shows progress, one clip at a time (Subtitle Removing: 43% …).
  7. Wait for Done: 1 cleaned …, then press any key to close the Terminal.
  8. Open the result in Desktop › Caption Remove › Out and scrub through where the captions were.

↻Running it again · batches

Clips that already have a _clean file in Out are skipped — top up In and click the icon any time.
To re-do a clip (new box or new mode): move or delete its _clean file from Out first, then click the icon.

The box you draw is saved and reused for every clip in that run. New batch, captions in a different spot? Just draw a new box when the window opens.

⚙settings.txt — the mode

Normally untouched (the box you draw writes the ZONE lines). The one line worth knowing is MODE=. Open in TextEdit, change, save.

sttn-det
Default. Finds text inside your box and repairs only those frames. Fastest. Very rarely misses a frame (caption flashes on for a moment).default
sttn-auto
Repairs the whole box on every frame. Never misses — but anything passing through the box (a hand) gets smoothed too. Keep the box tight.
propainter
Best quality on movement, about 3–4× slower. For a hero clip when the default leaves a visible patch.

!If something goes wrong

"Nothing in In"
In is empty, or the file isn't .mp4 / .mov / .m4v.
"FAILED — left in In"
That clip errored; the others continue. Try it alone and send Claude the Terminal lines just above the word FAILED.
Picture window doesn't open
First time, macOS may ask to let Python control the screen — allow it and click the icon again.
Opened the icon twice
In the extra picture window press Esc, then in its Terminal press Ctrl+C and close that window.
"Operation not permitted"
System Settings › Privacy & Security › Files and Folders › Terminal → allow Desktop.
